## PPC rules (Production Planning dashboard)
- One colour per SKU (15 Nov 2026), worked out from the data - do not trust the sheet's Auto Status when it conflicts:
  1. RED = overdue: ship date passed (first filled of Ship Date (2) → Effective Ship Date → Revised Ship Date → Ship Date) AND Ship date Actual empty. Red always wins.
  2. Otherwise the sheet's Auto Status (Purple, Yellow, Orange, Green, Light / Medium / Dark Blue).
  3. Auto Status blank or #REF! and not late → Green.
  Only one chip per SKU ("Red - overdue"; no second "Late" chip). The Late count, the Overdue Only filter and the colour counts all use this same rule, so Red count = Late count.
